⚔️ Shadow OS — Engineer's Guide

A capability-first cognitive engine: 7 shadows orchestrated by Monarch, each running one loop, sitting on an AIOS-style resource kernel.

Capabilities, not names · one 4-stage loop · Monarch absolute · runs on a real kernel

Architecture · three honest layers

The system is deliberately split. The engine decides which shadow reasons about what; the kernel decides which request gets LLM, memory, and tools. They are complementary, not the same thing — which is exactly why this is not "AIOS" but runs on an AIOS-style kernel.

How Monarch orchestrates one run

A directive flows through Monarch like this. Steps 1–2 are Monarch's intake; 3–4 route and run the fleet; 5–6 enforce the laws and learn.

ReconstructStrip surface ask → intent, beliefs, γ (System 1/2), signal-to-noise.
ClassifyRegex-first task class (zero API cost): compression, research, commercial…
Route loadoutDispatch table → primary + support shadows. Memory may recall a winning loadout.
SequenceRun each shadow's loop; thread each artifact into the next.
RatifyThresher's release gate. Nothing ships unless it passes (Monarch absolute).
Learn + logRecord loadout in TKL, emit RSI, deposit to memory (compressed first).

Kernel · the resource layer's capabilities

When Monarch is given a kernel, the fleet runs on it: completions share one accounted model, each shadow is access-checked, loop state is snapshotted, and shipped output persists.

LLM Core llm_core.py

One shared model across all agents, with call + token accounting.

Scheduler scheduler.py

Priority ordering of dispatched agent jobs (lower number runs first).

Context Manager context.py

Deep snapshot / restore of an agent's loop state on context-switch.

Storage + Memory storage.py

JSON-persistable key-value store + LRU-bounded memory manager.

Tool Manager tools.py

Unified tool registry; every call is permission-checked first.

Access Manager access.py

Per-agent permissions. Example: Aegis may touch pipeline data, Ira may not.

How to use it

Install

pip install -e .     # no required dependencies; Python 3.10–3.11

Run the engine (offline by default)

# standalone — MockLLM, no API key needed
from shadow_os import Monarch

monarch = Monarch()
task = monarch.run("tighten this bloated proposal deck")

print(task.final_output)   # ratified by Thresher's gate, then shipped
print(task.trace())        # task_class, loadout, γ, RSI, governance

Run on the kernel (full stack)

from kernel import Kernel
from shadow_os import Monarch

kernel  = Kernel()
monarch = Monarch(kernel=kernel)          # boots the fleet onto the kernel
task    = monarch.run("draft the Hexaware proposal summary")

kernel.llm_core.usage()                   # {'calls': 3, ...} shared + accounted
len(kernel.memory)                        # shipped output persisted

Wire a real model (model-agnostic)

from shadow_os import Monarch
from monarch.llm import CallableLLM

def my_model(system, user):
    ...                                   # call your provider; return text
    return text

monarch = Monarch(llm=CallableLLM(my_model))

Command line

python -m shadow_os.cli "research why retention dropped" --trace
python -m shadow_os.cli --personal "I'm stuck on how to approach the launch"
python -m monarch.cli "draft the launch note"     # the v1.1 pipeline

Runnable demos & tests

python examples/run_engine.py     # routes 5 directives across the fleet
python examples/run_on_kernel.py  # accounting, access control, scheduler

Real Claude adapter

ClaudeLLM tiers the shadows: Sonnet 4.6 (adaptive thinking) for normal work, Haiku 4.5 for clear tasks, with prompt caching on the per-shadow system prompt. Opt-in via pip install -e ".[claude]" + ANTHROPIC_API_KEY; offline default unchanged.

done

Notion-backed memory + embeddings

Memory can persist to a Notion database (NotionStorage) with cosine-similarity search via a pluggable embedder. Going live needs NOTION_TOKEN + VOYAGE_API_KEY; offline default needs neither.

Encode each shadow's mental models & modes (e.g. Thresher's two-phase compression, Aegis's signature moves) beyond the shared prompt.

later
